# Friend Test

Use this with every new Geoffrey pilot. Do not take over their computer unless they ask; observe where Geoffrey itself is confusing.

## Before They Arrive

- Use a clean Mac user account when possible.
- Confirm they can sign in to Claude and their email account.
- Have the Geoffrey installer command ready.
- Do not pre-create their GitHub account or connect their private accounts.

## The Test

1. Ask them to install Geoffrey using only the written instructions.
2. Ask them to create or sign in to GitHub when Geoffrey asks.
3. Ask them to connect every email/calendar account they actually use.
4. Ask them to open Geoffrey and run their first briefing.
5. Ask them to give feedback on one item in the briefing.
6. Ask them to add a second account or repair a connection without coaching.
7. Ask them to request one small piece of real work, such as a schedule for tomorrow or a list of urgent email follow-ups.

## Record These Things

- Where did they hesitate?
- What wording did they misunderstand?
- Which request created visible value first?
- What did they expect Geoffrey to do that it could not?
- Did they ever feel they needed to understand Terminal, GitHub, or Claude Code?
- What would make them use it tomorrow morning?

Add each finding to [Feedback](FEEDBACK.md), then turn recurring findings into roadmap work.
