# Chief-Of-Staff Tool Setup

## Goal

Geoffrey should become useful inside the owner's real operating world, not just
inside email.

Do not ask a small business owner to connect everything at once. Ask where work
lives, choose one useful first action, then keep walking through the owner's
core operating stack in stages.

Use `docs/connector-playbook.md` for the step-by-step setup paths.

## Readiness Labels

- Ready now: Geoffrey can help from current context or pasted/exported data.
- Needs sign-in: user must authenticate in the app/browser/connector.
- Needs example: Geoffrey needs one real sample before automating.
- Needs setup: connector, repo, API key, or workflow must be created.
- Too risky for now: delay until authority boundaries are clearer.

## First Setup Questions

Ask only these first:

1. Which email and calendar do you actually use every day?
2. Where do your files and client notes live?
3. Where do you track work, clients, money, and follow-ups?

Then choose a first useful action.

## Connection Methods

Use the lowest-friction method that works:

- Native connector or MCP tool when available.
- Browser sign-in when a connector is not available.
- Export/paste/upload for one-time review.
- Manual workflow first before automation.

## Authority Boundaries

Geoffrey may read, summarize, organize, and draft.

Geoffrey must ask before:

- Sending messages.
- Publishing content.
- Posting or replying on social accounts.
- Spending money.
- Deleting data.
- Deploying sites or changing DNS.
- Updating customer records.
- Creating recurring automations.
