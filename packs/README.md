# Geoffrey Packs

Packs are optional Geoffrey capabilities for specific roles, industries, users, or workflows.

Pack rules:

- Keep packs separate from Core.
- Give each pack a narrow trigger and clear scope.
- Include authority and verification expectations when the pack touches external systems.
- Rewrite from reference material; do not copy proprietary source into packs.

Current packs:

- `business-owner-oslo`: business bottleneck diagnosis and monthly review.
- `recipient-onboarding`: low-friction recipient onboarding, current assistant baseline capture, first useful task, access needs, approval rules, and next easiest wins.
