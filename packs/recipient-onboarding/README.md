# Recipient Onboarding Pack

This pack helps Geoffrey start with the person receiving it.

It is intentionally recipient-specific but not tied to one person:

- ask a few practical questions
- reduce load with one useful task quickly
- capture the current assistant or manual-work baseline through real use
- identify access needs and approval boundaries
- remember preferences and standards
- suggest the next easiest win

For Mauricio, the current assistant baseline is Viktor. For another recipient, the baseline may be ChatGPT, Claude, an executive assistant, a virtual assistant, a team member, or no assistant at all.
