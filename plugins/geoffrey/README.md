# Geoffrey Claude Plugin

This plugin bundles the Geoffrey skill set for one-file installation in Claude Desktop or plugin-based Claude Code workflows.

Install package:

```text
dist/Geoffrey-Claude-Plugin.zip
```

Included skills:

- `geoffrey`
- `execute-and-verify`
- `context-management`
- `authority-management`
- `geoffrey-onboarding`
- `business-owner-oslo`
- `recipient-onboarding`
